# 开题报告参考文献原文

本文件夹存放开题报告所引 25 篇文献的原文 PDF，用于从原文截取 PPT 研究背景所需的图。

仓库是公开的，`.gitignore` 已让本文件夹里的 PDF 不进入 git，PDF 只保存在会话环境中。
上传方式见对话说明；文件名不限，收到后统一重命名为 `编号_第一作者_年份.pdf`，如 `20_Galvan-Ampudia_2020.pdf`。
如有补充材料（Supplementary），请一并上传，放在 `supplementary/`。
