# 结构改动六：WUS 门控生长素响应（先于运行写定）

写定时间：2026-10-28。基础：主线 v2（`../frozen_v2/`），由小长大起始，运行到 1700，分析 1250–1700。v3（`../detuned_v3/frozen_v3/`）上的检查是可选的第四步。
状态：只有方案，没有运行；第一步要用的实测量还没测。
修订一（2026-10-28，任何运行与测量之前）：Galvan-Ampudia 2020 的 DR5 边界数据对照原文核实，E2 改称一致性检查；
写明 Th、ρ_far 不重新标定；种子成对比较；g_lb 的线性预测改为一阶预测；第一步加测量口径检查，ρ_P0 改用逐茎尖比值。

## 为什么改

主线 v2、v3 里，"中心区不起始原基、没有 DR5 样读出"都是硬规定：

- 起始只在 `R_c ≤ r < R_p` 的环里判定，`R_c` 取实测 CLV3 区半径；
- 读出 R 乘以 `comp = 1(r ≥ R_c)`，中心区恒为 0。

数据给出的图景是：中心区生长素高，但转录响应低（见依据）。本改动把这两条硬边界换成一个依赖 WUS 的生长素响应门控，
用有文献依据的机制代替规定，并为以后让中心区成为高生长素区留出余地。

## 依据（2026-10-28 用 Crossref 核对出处，用摘要或全文核对内容）

| 文献 | 内容 | 在本方案中的用途 |
|---|---|---|
| Ma et al. 2019, *Nat Commun* 10:5093 | WUS 以"变阻器"方式压低干细胞的生长素信号与响应；干细胞需要低而不为零的信号（在干细胞里阻断信号，pCLV3:BDL-D，T1 代 45/90 茎尖终止）；DR5 最低处与 CLV3 区重合（图 1） | 门控依赖 WUS，且有下限 g_min > 0 |
| Vernoux et al. 2011, *Mol Syst Biol* 7 | 茎尖中心积累相当多的生长素，但敏感性低、转录输出低；归因于 ARF 激活子在中心低表达，未涉及 WUS | 支持"门控响应、不门控生长素水平"，不支持门控来自 WUS |
| Galvan-Ampudia et al. 2020, *eLife* 9:e55832 | SAM 中心是常驻的高生长素区，P−1、P0 也是汇聚区；离中心最近的 DR5 表达细胞在 32 ± 7 µm（SD）处，此处 CLV3 报告基因强度低于最大值的 5%（2026-10-28 对照原文核对） | 设计依据之一，所以 E2 只算一致性检查，不算独立检验 |
| Plong et al. 2021, *Nat Commun* 12:6361 | L1 中有核 WUS（野生型 L3:L1 约 3），水平受 CLV3 双重调控而稳定 | 支持用固定的 WUS 场 |
| Schoof et al. 2000, *Cell* 100:635–644 | WUS 诱导 CLV3 | 用 CLV3 区作为 L1 中 WUS 活性区的代理 |
| Gruel et al. 2016, *Sci Adv* 2:e1500989 | WUS、CLV3 区面积随茎尖大小缩放 | 由小长大阶段，门控随 R_c 等比缩放 |

## 改动内容

现在：

    dM/dt = (A − M) / τ_M
    起始：R_c ≤ r < R_p 且 M − inh ≥ Th
    读出：dR/dt = (comp·H(M) − R) / τ_R，comp = 1(r ≥ R_c)

改为：

    dM/dt = (g·A − M) / τ_M
    起始：r < R_p 且 M − inh ≥ Th          （去掉内边界）
    读出：comp ≡ 1                         （门控已经在 M 里）
    g(r, t) = 1 − (1 − g_min) · ĉ(r / R_c(t))

- ĉ(ρ)：实测 CLV3 径向剖面，归一到 0–1，ρ = 到中心距离 / CLV3 半径（第一步）。它是 L1 中 WUS 活性区的代理。
- 由小长大阶段 R_c(t) 从 2.0 增到 5.5，门控按 ρ 等比缩放；分析时段（t > 600）内 g 不随时间变。
- 含义：在 WUS 区内，生长素对转录响应的作用被压到 g_min 倍，区外为 1。门控只作用于转录响应（时间积分 M 与读出 R），
  不作用于生长素水平、运输和 PIN 分配。中心区的低 PIN（pin_cz = 0.2）、本地产生 ρ_in、外围源全部不动——一次只改一处。
- 阈值 Th 与外围产生率 ρ_far 不重新标定：两者的标定规则针对生长素 A，而门控不改变 A。门控削弱环内缘的响应、使起始外移，是要检验的预测，不加补偿。

实现：在 `wus_v6/` 里写 `GatedSim(TwoLayerSim)`，导入 `../frozen_v2/` 的代码。需要改的 `run` 与 `_geometry` 两个函数复制过来，
只改上面三处；运行前把与 frozen_v2 的差异存为 `wus_v6/DIFF.txt`，并记录代码与本方案的哈希。`model.py`、`frozen_v2/`、`frozen_v3/` 不动。

## 一、测输入 ĉ(ρ)（只用 CLV3 通道）

21 个茎尖（与 `../calib_v2/` 相同），0 h，L1 细胞核（`*_aligned_L1_normalized_signal_data.csv`）。

1. 每个茎尖：ρ = `radial_distance` / `clv3_radius`，0–2.0 分 40 格，每格取 `Normalized_CLV3` 的中位数 c(ρ)；
   c_0 = ρ < 0.3 各格的均值，c_far = 1.6 ≤ ρ < 2.0 各格的均值；ĉ = (c − c_far) / (c_0 − c_far)，截到 [0, 1]，再做单调递减的保序回归。
2. 21 个茎尖逐格取中位数作为 ĉ；报告四分位带，以及 ĉ = 0.5、0.1、0.05 处的 ρ。
3. 不看 DR5、qDII。

两项只靠数据、在任何模型运行之前完成的检查，结果写入 `out/c_hat.json`：

- **测量口径**：论文报告 DR5 内边界处（32 µm，ρ ≈ 1.17）CLV3 低于最大值的 5%。若这里测得 ĉ(1.17) 明显高于 0.05（> 0.1），
  说明我们的归一化与论文不同，先查测量，再继续。
- **P0 处的门控**：用每个茎尖的 P0 半径 / CLV3 半径（`../calib_v2/` 已有）取中位数得到 ρ_P0（按群体中位数约为 29.0 / 27.3 ≈ 1.06）。
  若 ĉ(ρ_P0) > 0.5，"门控形状等于 CLV3 剖面"会把起始推到实测 P0 之外，预期 E1 不通过，说明门控边缘应在 CLV3 半高之外。

## 二、基线诊断（模型不改）

frozen_v2，ρ_in = 0、2，各 16 个种子（与冻结版逐位相同），只多记录分析时段内中心区（r < R_c）每个细胞的 M（每 25 步一次）。
在门控运行之前算出两个量，写入 `out/baseline.json`：

- **g_lb**：在 0.01 的格点上，使所有中心区细胞、所有时刻都满足 g(r)·M_基线 < Th 的最大 g_min。
  漏积分是线性的：若 A 不变，门控后的 M 就等于 g × 基线 M。但门控同时削弱环内缘的响应、使起始外移，会改变 A，
  所以 g_lb 只是对"中心区是否起始"的一阶预测，偏差大小本身也是结果。
  计算时不计排除半径和次级场，两者只会让起始更难，所以 g_lb 偏保守（偏低）。
- 中心区与环内生长素 A 的均值比（E3 的基线）。

## 三、运行

frozen_v2，ρ_in = 0、2，各 16 个种子，由小长大起始，运行到 1700，分析 1250–1700。
种子与冻结版相同（1–16），各组与基线按种子成对比较。

| 组 | 设定 | 作用 |
|---|---|---|
| C0 | 去掉内边界，不加门控（g ≡ 1，comp ≡ 1） | 检验内边界是否在起作用；也是"失去 WUS 门控"的类比 |
| C1 | 阶跃门控：ĉ = 1(ρ < 1)，g_min = 0 | 回归，应与基线相同 |
| S | 实测形状 ĉ，g_min = 0、0.1、0.2、0.3、0.5、0.7 | 主要结果 |
| W | ĉ 的边缘宽度 ×0.5、×2（绕 ĉ = 0.5 处沿 ρ 伸缩），g_min = 0.2 | 对代理剖面形状的敏感性 |

共 (1 + 1 + 6 + 2) × 32 = 320 次，加第二步的 32 次。g_min 没有测量值，6 个取值全部报告，不挑。

## 评价量（都不用于设定任何参数）

- **E1 起始半径**（µm，1 单位 = 4.91 µm）：实测 P0 29.0 µm（四分位 26.0–33.3）。
- **E2 读出内边界**：模型的读出 R 与数据的 `Normalized_DR5`（21 个茎尖，0 h）用同一定义——沿径向取方位 90 百分位，
  内边界为第一次达到其最大值一半处的 ρ。数据端用同一程序计算，并与论文的 32 ± 7 µm 并列。
  "响应边界在 CLV3 区边缘"本身是设计依据，所以 E2 只检查模型动力学是否保持这一关系，不算独立检验；独立的评价量是 E1、E3、E4。
- **E3 中心区生长素**：中心区与环内 A 的均值比，与基线比较；数据端为 1−qDII 从中心到 P0 接近饱和（定性）。
- **E4 叶序统计**：是否规则与类型、平均夹角、P1–P5 离散、非规范夹角、间隔 CV、同时起始比例；另记中心区起始次数（起始时 r < R_c）。

## 预期与判定（先写定）

1. **C0**：出现中心区起始，至少一半运行在分析时段内有 ≥ 1 次。依据是结构改动一中中心区生长素不低于环内，而阈值是环内无原基水平的 0.82。
   若不出现，说明内边界不起作用，门控不会改变叶序、只改变读出；第四步不做。
2. **C1** 与基线无差别：每个 ρ_in 的规则数相差 ≤ 2/16，平均夹角相差 ≤ 1°，起始半径相差 ≤ 0.5 µm。不通过则先查实现，不解读 S。
3. **S**：
   - g_min < g_lb：没有中心区起始；叶序统计在 C1 的容差内；起始半径向外移，幅度不超过 (ρ(ĉ = 0.05) − ρ(ĉ = 0.5)) × 27.3 µm。
   - g_min 明显大于 g_lb：出现中心区起始，g_min 越大越接近 C0。
   - 转折应落在 g_lb 两侧相邻的两个格点之间。若不在，说明门控经由起始或汇改变了中心区自身的生长素，线性预测失效，如实报告。
4. **E2**：读出内边界从基线的 R_c（阶跃）外移到 ĉ 较小处，估计在 ρ(ĉ = 0.1) 与 ρ(ĉ = 0.05) 之间；与数据端同一定义的结果比较。
5. **E3**：在没有中心区起始的组里，中心区与环内的生长素比和基线相同，因为门控不碰生长素水平。
   这说明模型允许"中心区生长素高而不起始"，但不会让中心区变高——后者仍取决于运输，不在本改动范围内。
6. **W**：边缘越宽，起始半径越向外。若 ×2 使 E1 落出实测带而 ×0.5 没有，记录为"结果依赖于代理剖面的边缘宽度"。

## 四、v3 上的检查（可选，是否做由用户决定）

v3 的 120 组参数 × 2 个种子，加 S 门控，g_min = 0 与 0.2，共 480 次；与 `../detuned_v3/RESULTS.md` 的各项分布比较，判断 v3 的结论是否改变。

## 并入主线的条件

本方案不决定并入。若 C1 通过、S 中存在不产生中心区起始的 g_min 区间、且 E1 在实测带内，则向用户提议：
在 v3 的抽样中加入门控，g_min 作为抽样参数（范围 0 到 g_lb）。g_min 不按叶序统计选定。

## 不做的事

不按叶序结果调 ĉ 或 g_min；不让门控作用于 PIN 分配或生长素水平；不动 pin_cz、ρ_in 和外围源；不引入 WUS–CLV3 动力学。

## 局限（先写明）

- WUS 场是给定的（用 CLV3 剖面代理），没有动力学，也没有生长素、细胞分裂素对 WUS 的反馈，所以这一步检验不了 clv3、WUS 过表达等扰动。
- 用 CLV3 代理 WUS 活性：CLV3 是 WUS 的帽形靶标（WUS 过高时反被抑制），在 L1 里两者大体同区，但边缘未必重合。
- 模型区分不了"WUS 变阻器"（Ma 2019）与"ARF 分布"（Vernoux 2011）两种来源，两者给出同样的门控。
- Plong 2021 的模型不直接使用，只作为"L1 中 WUS 水平稳定"的依据。
- 中心区横向大小仍是输入。要让它随茎尖大小自己形成并做 clv3 扰动，需要 Gruel 2016 那类表皮信号模型，留作后续。
