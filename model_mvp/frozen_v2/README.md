## 内层取值是怎么选的（看过结果之后的选择）

`../v3_layer/` 预先报告了 8 种组合。这里按一条不涉及叶序统计的规则选：
在 ρ_in = 0 和 2 两档上都满足 PL1（原基保持在阈值以上 ≥ 1 个间隔）、PL2（读出过半开启、滞后 0.5–1.5 个间隔）、
且远离原基处读出开启比例 ≤ 2%。8 种组合中只有 (k_v, K_e, η2) = (0.3, 3, 3) 满足。
这条规则是在看到结果之后定的，所以这一选择不能算作对内层的检验；所有组合的叶序结局相同（全部规则螺旋）。
