# 结构改动三：细胞间 PIN 量的随机差异（先于运行写定）

写定时间：2026-10-14。基础：主线 v2（`../frozen_v2/`）在标定后的几何上（`../calib_v2/`：发生环内半径 5.57，1 个模型单位 = 4.91 µm，
外围产生率取 `../calib_v2/out/geometry.json`）。

## 为什么改

`../calib_v2/RESULTS.md`：模型远比实测规则——非规范夹角 0% 对 15%（Besnard 2014 野生型），P1–P5 离散 3.1–3.4° 对 6.7°，
原基间隔变异系数 0.14–0.15 对 0.22。模型除细胞网格外没有任何随机性来源。

## 依据

- 植物表皮中基因表达存在细胞间的随机差异（例如 Meyer et al. 2017，eLife，萼片表皮中 ATML1 的波动决定巨型细胞的分布）。
- 茎尖表皮的 PIN1 荧光在相邻细胞之间差别明显（PIN1-GFP 成像）。这一点是定性的，本轮不引用具体数值。
- 选 PIN 量而不是生长素合成作为随机来源：在 ρ_in = 0 的设定下，分生组织内没有本地合成，合成噪声只作用于外围；
  PIN 量作用于包括发生环在内的所有细胞。这是建模上的选择，另一种通道本轮不测，记为未做。

## 改动内容

1. 每个细胞的 PIN 总量乘以随机因子 ξ_i = exp(σ z_i − σ²/2)，z_i 为标准正态，平均值为 1。
2. 细胞分裂时两个子细胞各自重新抽取 ξ；不分裂的细胞保持原值，所以一个因子大约持续一个细胞周期。
3. 随机数使用独立的随机数流，不影响网格和初值。其余一概不变。σ = 0 时必须与不加噪声的运行逐位相同（先核对）。

## σ 的确定（只用一个非叶序统计量，定完不再改）

**统计量 s：高生长素区相邻细胞之间的局部残差。**
- 数据：21 个茎尖 × 3 个时间点，对齐后的 L1 核。取径向 15–50 µm 环带内、生长素（1 − qDII）高于该环带中位数、且 qDII ≥ 0.02 的细胞；
  每个细胞的邻居是 7 µm 内的其他 L1 核（至少 3 个）；残差 r_i = ln qDII_i − 邻居 ln qDII 的平均；s = SD(r) / sqrt(1 + 1/k̄)（k̄ 为平均邻居数）。
  每个茎尖每个时间点得到一个 s，取全部的中位数 s_data，并报告四分位。
- 模型：同一函数作用于 ln A（细胞中心坐标乘 4.91 µm，同样的环带、中位数筛选和 7 µm 邻域），终值几何直接起始，运行到 400，
  200–400 每 10 个时间单位采样一次，4 个种子。
- 理由：高生长素区 qDII ≈ K/A，ln qDII 的局部残差与 −ln A 的局部残差相同，与传感器常数 K 无关。
  已知偏差两个方向相反：测量噪声使 s_data 偏大；A/K 不够大时传感器压缩残差，使 s_data 偏小。
- σ* = 使 s_model(σ) = s_data 的 σ，在对数尺度上二分，ρ_in = 0 与 2 分别确定。若 σ = 0 时 s_model 已不小于 s_data，则 σ* = 0，照实报告。

## 运行

σ ∈ {0, σ*/2, σ*}，ρ_in ∈ {0, 2}，由小长大起始（与主线相同），每格 16 个种子，分析 1250–1700。
另在 σ* 下做关掉极性运输（T = 0）的对照，每档 3 个种子，终值几何直接起始，运行 300。

## 预期与判定

- **N1（主要）：** 非规范夹角比例、P1–P5 离散、间隔变异系数三项都随 σ 单调上升（0 → σ*/2 → σ*），两档 ρ_in 都如此。
- **N2：** 在 σ* 下，至少一档 ρ_in 同时满足：非规范夹角比例在 9–21%、P1–P5 离散在 4.0–9.4°（实测值 ±40%）。间隔变异系数照实报告。
- **N3：** σ* 下 T = 0 不产生原基。
- **N4：** 平均夹角、起始半径、G、规则的种子数照实报告。预期平均夹角基本不变（随机性不应改变系统偏差）。
- 若 σ* 下叶序失序（规则少于 8/16），照实记录，不回头调 σ。
- 不根据叶序结果调整 σ、换噪声通道或改统计量的定义。

## 标定结果（2026-10-14，叶序运行之前；按方案无法得到 σ*，叶序运行暂停）

1. s_data = 0.224（四分位 0.214–0.235，21 个茎尖 × 3 个时间点 = 63 帧，`out/data_log.txt`）。
2. 模型：σ = 0 时 s = 0.062（ρ_in = 0）/ 0.064（ρ_in = 2）；σ = 2.0 时 s = 0.141 / 0.116（`out/calib_log.txt`）。
   σ = 2.0 已对应细胞间 PIN 量相差数倍，仍到不了 s_data：模型中的扩散与运输把细胞尺度的 PIN 差异大部分抹平了。
   方案只考虑了“σ = 0 已超过 s_data”的情形，没有考虑“任何 σ 都到不了”，因此 σ* 无定义。
3. 事后核对 s_data 本身（同一批细胞、同一统计量）：DII-VENUS 0.190，TagBFP 0.155（组成型参照，不响应生长素），CLV3 0.252，DR5 0.344。
   若 DII-VENUS 带有与 TagBFP 同量级、彼此独立的表达与测量噪声，仅此就使比值的残差约为 0.22，即 s_data 可能几乎全是报告基因层面的噪声。
   所以 s_data 不能作为“生长素细胞间差异”的可靠锚点；第 1 条的“已知偏差”远比预想的大。
4. 在用户决定如何修订之前，不运行任何叶序模拟。

## 修订一（用户选择“先扫剂量，再用 PIN1 数据检验”，2026-10-15，任何叶序模拟之前）

**改为两步：先由模型推断需要多大的 PIN 差异，再用 PIN1 成像直接检验。** 原“σ 的确定”一节作废；N1、N3、N4 保留，N2 改写如下。

第一步：剂量扫描（不标定）。
- σ ∈ {0, 0.25, 0.5, 1.0}，ρ_in ∈ {0, 2}，由小长大起始，每格 16 个种子，分析 1250–1700；σ = 1.0 时做 T = 0 对照（每档 3 个种子）。
- 推断：对每档 ρ_in，求非规范夹角比例（实测 15%）和 P1–P5 离散（实测 6.7°）各自首次达到实测值的 σ：
  在 0.25、0.5、1.0 之间按 ln σ 线性插值；若首次在 0.25 达到，记为“≤ 0.25”（0 与 0.25 之间不插值）；到 1.0 仍未达到，记为“> 1.0”。
  两者取较大者为 σ_need。各统计量取 16 个种子的中位数。
- 这是用叶序统计反推出的量，**只作为对 PIN1 测量的预测，不进入模型参数**。

第二步：PIN1 成像检验（数据：Zenodo 3737795 中的 E35、E37，4 个 qDII–CLV3–PIN1–PI 茎尖 × 4 个时间点）。
- 测量方法在查看任何 PIN1 数值之前另行写定（细胞水平的 PIN1 总量如何从成像中得到，取决于作者分割管线能否运行，需先检查）。
- 预测：测得的细胞间 PIN1 量对数标准差（扣除参照通道噪声后）≥ σ_need 的 0.5 倍且 ≤ 2 倍，记“相符”；明显小于 0.5 σ_need，
  记“PIN 量的随机差异不足以解释实测的不规则”；σ_need > 1.0 时，只要测得值 ≤ 1.0 即记为“不足”。

新的 N2：两档 ρ_in 都报告 σ_need；判定留到第二步。

## 修订二：PIN1 的测法（2026-10-15，下载 PIN1 数据期间、查看任何 PIN1 数值之前写定）

管线：作者的 `sam_experiment_segment_and_quantify_polarities.py` 路径（PI 膜染色分割 → 提取 L1 垂周壁 → `quantify_wall_membrane_signals`），
每面壁输出两侧各自的强度 `left_PIN1`、`right_PIN1`、`left_PI`、`right_PI` 和两侧细胞编号。图像裁剪沿用 `../calib_v2/PROTOCOL.md` 修订二的自动裁剪（CLV3 中心 60 µm 圆柱），通道数按 PIN1 品系改为 5 个。

- 细胞 c 的值：P_c = c 的各面 L1 垂周壁上属于 c 那一侧的 ln PIN1 的平均；Q_c 同法取 ln PI；X_c = P_c − Q_c（扣除深度与光学衰减）。
- 区域：细胞中心距茎尖中心 15–50 µm（茎尖中心取各细胞中心按 CLV3 信号加权的质心），四个时间点都用；不做高低筛选（PIN 噪声作用于所有细胞）。
- 邻居：与 c 共壁的细胞，至少 3 个。残差 r_c = X_c − 邻居 X 的平均；s_X = SD(r) / sqrt(1 + 1/k̄)；对 Q 同法得 s_Q。
- 细胞间 PIN1 差异的估计 σ_PIN = sqrt(max(s_X² − s_Q², 0))；同时报告未扣除的 s_X（上限）。每个茎尖每个时间点一个值，取中位数。
- 与模型的对应：模型中细胞 PIN 总量 ∝ 面积 × ξ，即单位膜长度上的 PIN 密度 ∝ ξ；壁侧平均强度对应密度，所以 σ_PIN 与模型的 σ 同义。
- 若作者的分割管线在这些数据上无法运行，先报告，不改用其他测法，除非另写修订。

## 修订三：加密剂量网格（2026-10-15，第一步结果出来后、PIN1 数据处理之前）

第一步（`out/dose_report.txt`）显示 σ = 0.25 时仍规则（15–16/16），σ = 0.5 时已大多失序（1–6/16），两者之间是陡变；
按 ln σ 在 0.25 与 0.5 之间插值得到的 σ_need（0.31 / 0.40）很粗。为使给第二步的预测可靠，加做 σ ∈ {0.3, 0.35, 0.4, 0.45}，
其余设置不变（两档 ρ_in、每格 16 个种子、同一起始与分析时段）。σ_need 在合并后的网格上按原规则重算，第二步的判定用重算后的值。
另作描述性报告：网格中是否存在某个 σ，使非规范夹角在 9–21% 且 P1–P5 离散在 4.0–9.4° 同时成立。这一步不改变模型参数。

## 修订四：分割管线的 Python 3 兼容修补（2026-10-15，查看任何 PIN1 数值之前）

在 E35/SAM4 上试跑，作者的膜分割在第一张图上即报错：`segmentation_quantification.py` 第 220 行
`np.array(seg_volumes.keys())[np.array(seg_volumes.values()) > max_cell_volume]` 是 Python 2 写法，在作者镜像的 Python 3.7 中
`keys()`/`values()` 返回视图对象而不是列表。也就是说，这条分割路径按发布的样子在 Python 3 下从未能运行，与数据无关。

处理：只做不改变计算的兼容修补，逐条记录在 `../../reproductions/elife55832/docker/patches/PATCHES.md`，
以挂载副本的方式覆盖镜像中的对应文件，作者代码快照本身不动。修补 1：上述一行改为 `list(...)`
（Python 2 下 `keys()` 与 `values()` 即为顺序一致的列表，结果相同）。若后续遇到的不是此类兼容问题，而是需要改动算法或参数，停下并报告。

## 修订五：PIN1 只用每个茎尖的 0 h（2026-10-15 07:05，查看任何 PIN1 数值之前）

E35/SAM4 上的试跑：整条序列一起提取壁需要 15 GB 以上内存（被 WSL 的 15 GB 上限杀掉）；改为逐个时间点后，
0 h 一帧跑通（1268 面壁，表中有 `left/right_PIN1`、`left/right_PI` 与两侧细胞编号），但耗时约 3 小时（其中局部极性计算约 2.5 小时）、内存峰值约 14 GB，
一次只能跑一帧。16 帧全做约需 45 小时。因此：每个茎尖只用 0 h，共 4 帧；σ_PIN 取 4 个茎尖的中位数，并逐个报告。
这一缩减只出于计算成本，写定时尚未计算或查看任何 PIN1 数值（只看过列名与行数）。若之后放宽内存上限，可补做其余时间点，作为补充报告，不改变本修订的判定。
