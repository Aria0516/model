# 结构改动三：细胞间 PIN 量的随机差异——结果

**结论：实测的细胞间 PIN1 差异（约 8%）只有模型所需（32–48%）的 1/4 到 1/6；把实测值放进模型，叶序几乎和不加噪声时一样规则。
PIN 量的随机差异不足以解释实测的不规则，模型过于规则的原因不在这里。** 细节见文末“第二步”和“补充”两节。

方案：`PROTOCOL.md`（原方案 + 标定结果 + 修订一至三，均写在相应运行之前）。原始输出在 `out/`。

## 原方案的标定为何作废

- 数据侧统计量 s_data = 0.224（63 帧，四分位 0.214–0.235）。
- 模型：σ = 0 时 s = 0.062 / 0.064（ρ_in = 0 / 2），σ = 2.0 时仍只有 0.141 / 0.116：扩散与运输把细胞尺度的 PIN 差异抹平，到不了 s_data。
- 同一统计量用在单通道上：TagBFP（不响应生长素的参照）0.155、DII-VENUS 0.190。s_data 可能几乎全是报告基因层面的噪声，不能作锚点。
- 由用户决定改为：先扫剂量、由模型推断需要的 PIN 差异，再用 PIN1 成像检验（修订一、二）。

## 第二步：PIN1 成像检验

数据：Zenodo 3737795 中的 E35、E37，4 个茎尖 × 4 个时间点（10.9 GB），已全部下载并通过 MD5 校验。测法已在修订二中写定。

管线状况（2026-10-15）：
- 作者的膜分割在 Python 3 下有一处 Python 2 写法报错，按修订四做了不改变计算的兼容修补（`../../reproductions/elife55832/docker/patches/PATCHES.md`）。
- 调用时需加 `-s`（保存通道图像），否则后续的壁提取找不到序列。
- 整条序列一起提取壁超出 15 GB 内存；逐个时间点可行，但每帧约 3 小时、峰值约 14 GB，因此按修订五只用每个茎尖的 0 h。
- E35/SAM4 的 0 h 已完成（1268 面壁，691 个 L1 细胞，环带内可用 325 个）；其余 3 个茎尖依次处理中，约需 10 小时。
- 分析脚本 `pin1_measure.py` 已写好并在这一帧上检查过结构；统计值在 4 帧齐全后一起计算。

结果（`out/pin1_measure.txt`，每个茎尖 0 h 一帧）：

|---|---|---|---|---|---|

**判定（修订一）：** “相符”要求 σ_PIN 在 [0.5, 2] × σ_need 内，即 ρ_in = 0 时 0.16–0.64、ρ_in = 2 时 0.24–0.96。
实测 0.080 远低于两档的下限，记为 **“PIN 量的随机差异不足以解释实测的不规则”**。不扣除 PI 噪声的上限（中位数 0.119）也低于两档下限。

需要说明的：
- 只有 4 个茎尖、每个只用 0 h（修订五，出于计算成本）。
- 每个细胞的值是其各壁“本侧”PIN1 强度的平均，PIN1 本身的极性分布会使细胞间差异显得更大，因此 σ_PIN 只会偏大不会偏小；这不影响“不足”的判定方向。
- 平均每个细胞只找到约 4 个共壁邻居（真实约 6 个），作者的壁提取只保留了部分 L1 垂周壁。
- E35/SAM6 的 PI 自身残差（0.164）明显高于其余三个，这一帧的成像质量可能较差；去掉它，中位数为 0.080，结论不变。

## 由此得到的认识

1. 模型的生长素场在细胞尺度上非常平滑：PIN 量的细胞差异要放大到 30–50% 才会影响叶序，而实测只有约 8%。
2. 实测的不规则（P1–P5 离散 6.7°、间隔 CV 0.22、非规范夹角 15%）因此要从别处来。尚未检验的候选：生长素合成或降解的细胞差异、
   细胞分裂与生长的不均一、原基之间大小或起始时刻的差异；也可能是模型本身对噪声过于“稳健”（次级场与“跟随后定位”都在压制噪声）。
3. 实测的 qDII 局部差异（0.224）大半来自报告基因层面（TagBFP 自身就有 0.155），不能直接当作生长素的细胞差异。

## 是否并入主线

不并入。按实测值加入 PIN 差异几乎不改变任何统计量，并入只增加复杂度；`noise.py` 保留为已检验过的变体。
