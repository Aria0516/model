# 结构改动一的结果：环内生长素由极性运输供给

运行时间：2026-10-14。方案见 `PROTOCOL.md`（先于运行写定，R1 的补记写在叶序运行之前）。
原始输出：`levels_log.txt`、`patterns_log.txt`、`recheck_log.txt` 和 `out/`。全部 24 组都在下面，没有挑选。

## 1. 设计要求（无原基状态）

24 组中 20 组满足 R0（关掉运输时环内水平为有运输时的 12%–58%，低于阈值所在的 82%）。
不满足的 4 组都是向心偏置最弱（κ_c = 0.5）且源区较远或无本地产生的情况：偏置不足以克服指向源区的上梯度极化，
环外的 PIN 实际指向外侧（向心指数 −0.59 到 −0.76），运输反而把生长素运离分生组织。
绕环方向的细胞间差异在所有组都是 2%–6%，没有自发成峰。

## 2. 预期与结果

| 预期 | 结果 |
|---|---|
| P1 关掉极性运输不产生原基 | 成立：20 组、每组 3 次对照，原基数全部为 0 |
| P2 中央区生长素不低于发生环 | 成立：有原基的运行中，中央区/发生环为 0.98–1.76，20 组里 19 组不低于 1 |
| P3 PIN 向心指数为正 | 环内 +0.27 到 +0.68。这是设定的直接后果，不算预测 |
| P4 原基仍能依次产生；类型随源区位置改变 | 原基在所有组都能依次产生；规则性见下。类型随源区位置的变化不明显 |
| P5 复查之前通过的三项 | 手性无偏：仍成立（33 比 39，p = 0.56）。径向精度：仍成立（平均 0.15 个细胞）。对生起始过渡到螺旋：不再成立（见下） |

## 3. 叶序的规则性和类型（每组 8 个种子）

**基本型（瞬时定位、无次级场）：两种发生环、全部 20 组都不规则。** 规则的为 0–3/8，非规范夹角 29%–56%。

**冻结工作点的设定（跟随后定位加次级场）：**

发生环 3.5–5.5、汇范围 3（冻结版本在这里是螺旋，径向比约 0.58）：
- 类型变为二列互生（夹角 167°–176°，径向比 0.90–0.98）。
- 无本地产生的 5 组为 6–8/8 规则；有本地产生的 6 组里，κ_c = 0.5 的两组为 6/8 和 8/8，κ_c ≥ 1 的四组为 0–3/8。

发生环 5.5–7.5、汇范围 2（冻结版本在这里 45/48 规则，其中螺旋 41、Lucas 螺旋 4）：

| κ_c / 源区距离 / 本地产生 | 规则 | 其中的类型 | 径向比 |
|---|---|---|---|
| 0.5 / +2 / 2 | 3/8 | 螺旋 2，Lucas 1 | 0.32 |
| 1.0 / +2 / 0 | 6/8 | Lucas 4，螺旋 1，对生 1 | 0.32 |
| 1.0 / +2 / 2 | 6/8 | 螺旋 3，Lucas 3 | 0.30 |
| 1.0 / +4 / 0 | 5/8 | 对生 3，Lucas 2 | 0.34 |
| 1.0 / +4 / 2 | 7/8 | 螺旋 4，Lucas 3 | 0.30 |
| 1.5 / +2 / 0 | 6/8 | 螺旋 4，Lucas 2 | 0.31 |
| 1.5 / +2 / 2 | 2/8 | 螺旋 2 | 0.29 |
| 1.5 / +4 / 0 | 5/8 | Lucas 3，对生 1，螺旋 1 | 0.33 |
| 1.5 / +4 / 2 | 3/8 | 螺旋 3 | 0.29 |

9 组合计 72 次运行：规则 43 次（60%），其中普通螺旋 20、Lucas 螺旋 18、交互对生 5；不规则 29 次。
规则运行里无置换者的 P1–P5 角度离散为 3.9°–8.8°。

**对生起始（P5，9 组各 4 个种子，共 36 次）：** 规则 25 次，其中交互对生 13、螺旋 12；不规则 11 次。
也就是说，新结构下从一对相对的原基出发，交互对生可以维持下去，而冻结版本在同样的发生环上 16/16 都过渡到螺旋。

## 4. 小结

1. 改动的直接目的达到了，而且在取值范围内普遍成立：器官的产生依赖极性运输，中央区成为高生长素区。
2. 代价是类型选择变得不确定：同一组参数下，不同种子会得到普通螺旋、Lucas 螺旋或交互对生；普通螺旋不再占多数（72 次里 20 次）。
   没有次级场和跟随后定位时，全部不规则。
3. 这些结果没有经过任何针对叶序统计量的调整。四个新自由量里，只有 ρ_far 是按“无原基时环内水平等于冻结版本”确定的。
4. PIN 整体向心是直接设定的，模型没有解释它从何而来。

## 5. 没做的

- H1（去掉一个原基的汇）、H6（去掉次级场）没有在新结构上重做。
- 以老原基而非固定的外围环带作为源（更贴近论文所说的 P3–P5）没有试。
