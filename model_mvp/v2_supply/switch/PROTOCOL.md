# “分生组织内本地产生是对生与螺旋之间的开关”是否站得住（先于运行写定）

写定时间：2026-10-14。来源：`../why_types/RESULTS.md`，两组参数、各 16 个种子：由小长大时，本地产生为 0 走向交互对生（23/32），
为 2 走向普通螺旋（17/32）。

## 待检验的说法

在由小长大的起始下，分生组织内本地生长素产生 ρ_in 的多少决定结局是交互对生还是普通螺旋。

## 取值（全部报告）

- ρ_in：0、0.5、1、1.5、2、3。
- 向心偏置 κ_c：1.0、1.5。κ_c = 0.5 不纳入：结构改动一里该档在终值发生环上多数不满足“无运输时环内水平低于阈值”。
- 源区距离固定为 +2（之前 +2 与 +4 的结果相近）。
- 外围产生率按同一规则（无原基时环内水平为 4.0）对每个 ρ_in、κ_c 和发生环两端分别确定；阈值不变。
- 由小长大：每组 16 个种子。另在 κ_c = 1.0 下做直接从终值起始的对照，每组 8 个种子。
- 每组记录单个原基在环外 4 个细胞处对环内同方位的抑制深度（静态计算），用来对照机制。

**补记（第一次启动因多进程报错退出、未产生任何结果；重启前修改）。** `../ramp_mech/` 的 H-c 显示，由小长大后 650–1100 时段的
不规则多为尚未收敛的过渡，延长到 1250–1700 后大多收敛。因此本项的运行时间延长到 1700，主要判定改用 1250–1700 时段，
同时报告 650–1100 时段；直接起始的对照也运行到 1700，按同样两个时段报告。

## 预期与判定

- 预期：随 ρ_in 增大，交互对生的比例下降、普通螺旋的比例上升，两档 κ_c 都如此；转折点落在 0 与 2 之间。
- 判定：两档 κ_c 都满足“ρ_in = 0 时交互对生 ≥ 50%，ρ_in ≥ 2 时交互对生 ≤ 10%，且普通螺旋随 ρ_in 大体单调上升”，记“确认”；
  只有一档满足，记“部分”；都不满足，记“不确认”。
- 不满足“无运输时环内水平低于阈值”的组照样运行和报告，但单独标出。
- 附带检验：抑制深度随 ρ_in 增大而变浅；若深度与对生比例并不同向变化，记下来，说明抑制深度不是主因。

**补记二（运行中、任何结果出来之前写定）。** “大体单调上升”的操作定义：相邻两档 ρ_in 之间普通螺旋的次数下降不超过 2 次（16 次中），
且 ρ_in = 3 的次数不低于 ρ_in = 0。“ρ_in ≥ 2 时交互对生 ≤ 10%”指 2 和 3 两档各自 ≤ 1/16。
