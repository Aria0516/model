# 任务：校正茎尖上生长素最大区的发育编号（P−3 … P5）

## 背景

这里有 14 个拟南芥花序茎尖，代号 S01–S14，顺序随机。每个茎尖在 0 h、5 h、10 h 各成像一次，三个时间点已在同一个坐标系里对齐（原点为茎尖中心，单位 µm）。

茎尖侧面依次长出原基，相邻原基之间的方位角约为 137.5°，排成螺旋。每个原基在长出之前，先有一个生长素输入的局部最大区。按发育先后编号：

- **P0**：当前生长素输入最强、即将起始的位点，通常紧靠中央区边界（虚线圆）外侧；
- **P1、P2 …**：更老的原基，离中心更远；从 P0 起，每往老一个编号，方位角沿同一方向转约 137.5°；
- **P−1、P−2、P−3**：更年轻的预定位点，离中心更近、生长素最大区更弱，方位角也按 137.5° 依次推算（方向与上面相反）。

组织在生长，同一个器官在 5 h、10 h 时位置会略向外移动，但方位角基本不变。所以**同一个编号在三个时间点上应当指向同一个器官**；在 10 h 左右（接近一个发育周期），各位点的强弱会逐渐变化，但编号仍跟着器官走，不要在帧间重新编号。

管线已经自动检测出每帧的生长素输入极大点（红圈，带编号 `max_id`），也自动给了 P 编号（黑字 `auto P`）。自动编号是逐帧独立打的，常常在帧间不一致，需要你校正。

## 你拿到的材料（只有这些）

- `images/Sxx_00h.png`、`Sxx_05h.png`、`Sxx_10h.png`：每个茎尖每个时间点一张。颜色为生长素输入（1 − qDII，越黄越高）；红圈为检测到的极大点及其 `max_id`；黑字 `auto P` 为自动编号；白色虚线为中央区（CLV3 表达区）半径。
- `data/Sxx_00h_maxima.csv` 等：每帧的极大点列表，列为 `max_id, x_um, y_um, r_um, theta_deg, auxin_input_normalized, extremality, area, auto_P`。
- `data/Sxx_00h_nuclei.csv` 等：每帧表皮细胞核的位置和生长素输入（`auxin_input = 1 − qDII`）。

不要寻找或使用任何其他材料。

## 怎么做

1. 对每个茎尖，判断螺旋方向（从 P0 往老的编号走，方位角是逆时针还是顺时针增加），或标为不确定。
2. 在每个时间点，把极大点标成 P−3 … P5：每个编号每帧至多一个点；没有合适的点就留空；一个点只能给一个编号。只能从红圈的 `max_id` 中选。
3. 保证同一编号在 0、5、10 h 指向同一个器官。
4. 给每个标注一个把握程度：`high`、`medium`、`low`。

## 交回什么

1. `labels.csv`，每行一个标注：

```text
code,hour,P,max_id,confidence,note
S01,0,0,42,high,
S01,0,1,53,medium,
S01,5,0,40,high,与 0 h 的 42 为同一器官
```

2. `handedness.csv`：

```text
code,direction,confidence
S01,counterclockwise,high
S02,unclear,low
```

`direction` 取 `counterclockwise`、`clockwise` 或 `unclear`（指从 P0 走向 P1、P2 … 时方位角的变化方向，按图中的坐标）。

3. `method.md`：简述你怎么判断的；如果写了辅助代码，附上代码。
