# 茎尖生长素最大区的编号方法

以每个茎尖的 0 h 图确定 P0 和旋向，再把编号沿同一器官追踪到 5 h 和 10 h。42 帧共有 378 个可能的“帧 × 编号”组合，`labels.csv` 收录 271 个有对应红圈的标注，其余 107 个组合省略。每行的 `max_id` 只在该样本、该时间点的检测表内有效。

## 确定 P0 和旋向

在 0 h 对照虚线中央区边界、红圈位置、峰强度和周围细胞核的生长素输入。两个峰接近时，优先选择位于边界外侧、且相邻发育位点的半径和方位能连成螺旋的峰。按图中向右为正 x、向上为正 y 的坐标，从 P0 向较老位点角度增加记为逆时针，减小记为顺时针。跨越 ±180° 时取最短角差。两种旋向均与内外圈候选点比较，最终得到 8 个逆时针、6 个顺时针茎尖。

下表列出 0 h 有强东侧候选、最终将 P0 定在另一侧的样本。半径单位为 µm，信号取自同帧的 `auxin_input_normalized`。

| 茎尖 | 选定的 P0（方位，半径，信号） | 东侧候选（半径，信号） |
|---|---|---|
| S02 | #53（132°，37.2，0.663） | #41（21.6，0.661） |
| S04 | #39（133°，38.2，0.690） | #32（18.6，0.680） |
| S05 | #57（119°，41.2，0.709） | #38（27.2，0.691） |
| S08 | #15（−142°，33.8，0.740） | #20（26.0，0.739） |
| S10 | #27（−136°，38.9，0.741） | #42（26.0，0.740） |
| S13 | #20（−140°，33.4，0.730） | #31（17.8，0.719） |

S08、S10 两峰仅差 0.001。两者的东侧峰均在虚线内缘，随后增强，符合更年轻位点的表现。其 P0 定为 `medium`。相邻两个位点哪一个算 P0 的不确定性也影响这两个样本的其他编号。

## 跨帧选点与留空

用约 137.5° 的发散角定位扇区，再按半径把同方向的内圈和外圈分开。在已配准的三帧中比较亮区形状、角度、径向位移和附近红圈。几个红圈落在同一亮区时只选一个，结合峰强度、`extremality` 和前后位置决定。辅助代码还计算最近六个细胞核的距离加权平均输入，以及它与距红圈 10–22 µm 范围内细胞核输入中位数的差，供复核局部亮度。编号由三帧联合判读，`auto_P` 仅用于对照。

- **缺少检测。** S09 的 P−1 在 0 h 西南内圈可见亮区，但同方向的红圈远在外圈。保留 5 h 的 #27 和 10 h 的 #23，0 h 留空。
- **无法接续。** S05 的 P0 前两帧为西北 #57、#64。10 h 强峰明显偏内，其余候选的方位或半径偏离原轨迹，故该帧 P0 留空。S04 的 P−1 在 10 h 也有内外两种解释，保留前两帧。
- **只能作弱判断。** S03、S12 的 P−2 有连续的北侧亮带，但半径与较老位点重叠，三帧均记为 `low`。外围红圈若只落在暗区、着色区以外，或只有角度吻合而缺少可辨亮斑，则留空。

`high` 表示编号、局部峰与时间对应均清楚。`medium` 表示有可信的对应亮区，但起始编号、峰中心或邻帧位移仍有歧义。`low` 用于尚有局部信号支持的弱峰、边缘峰或半径异常的候选。旋向的置信度单独记录在 `handedness.csv`。

## 复核与复现

辅助代码为 `annotate.py`，使用 Python 3、NumPy 和 Pillow。从包目录运行。第一条命令核对两个交付文件和原始检测 ID，第二条列出指定样本的候选及核信号，第三条根据代码中保存的逐帧判读重新生成两个 CSV。

```sh
python annotate.py
python annotate.py --inspect S08
python annotate.py --write
```
