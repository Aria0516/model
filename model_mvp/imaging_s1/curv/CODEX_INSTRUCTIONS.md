# 任务：在茎尖表面上标出原基隆起，并判断它从哪个时间点开始可见

## 背景

这里有 14 个拟南芥花序茎尖，代号 M01–M14，顺序随机。每个茎尖在 0 h、5 h、10 h 各成像一次。原基从茎尖侧面长出时，表面会先出现局部隆起，之后隆起变得越来越明显。你的任务是只根据表面形态，找出这些隆起，并判断每个隆起第一次能看出来是在哪个时间点。

## 你拿到的材料（只有这些）

- `images/Mxx.png`：每个茎尖一页，三列是三个时间点，三行分别是：
  1. 表面明暗图（低角度光从左上方照射，橙色线为每 2 µm 的等高线）；
  2. 高度减去拟合圆顶后的起伏（拟合面为 z = a + b·x + c·y + d·r²，用 50 µm 以内的细胞核；橙色、棕色高于圆顶，紫色低于圆顶）；
  3. 平均曲率（红色为凸，蓝色为凹）。
- `data/Mxx_0h.csv`、`Mxx_5h.csv`、`Mxx_10h.csv`：表皮层每个细胞核的位置，列为 `x_um, y_um, z_um, mean_curvature, gaussian_curvature`。
- 三个时间点已配准到同一参考系，原点是 0 h 茎尖顶点在水平面上的投影，单位 µm。组织在生长，同一个隆起在后面的时间点会向外移动几个 µm。
- 图像外缘（离中心约 55 µm 以外）受裁剪影响，形态不可靠。

不要寻找或使用任何其他材料。

## 怎么标

1. 对每个茎尖，在每个时间点上找出看得出的隆起。茎尖顶部本身是一个大的圆顶，不算隆起；要找的是圆顶侧面局部鼓起的地方。
2. 把不同时间点上的同一个隆起对应起来（位置相近，后一时间点可能略向外）。
3. 对每个隆起，判断它**第一次能看出来**的时间点：
   - `0`：0 h 已经可见；
   - `5`：0 h 看不出，5 h 可见；
   - `10`：0 h、5 h 看不出，10 h 可见；
   - `unclear`：判断不了（例如位置在 0 h 的图像外缘、隆起时有时无、形态太弱）。
4. 每个隆起给一个把握程度：`high`、`medium`、`low`。

请以看图判断为主。如果你无法查看图片，请在结果里写明，并改用你自己设计的判据，同时把判据完整写下来。

## 交回什么

一个 CSV 文件 `labels.csv`，每行一个隆起：

```text
code,site_id,x_um,y_um,first_visible,confidence,note
M01,1,35.2,-18.0,5,high,在 5 h 出现，10 h 更明显
M01,2,-30.5,12.1,0,medium,
M02,1,...
```

- `x_um, y_um`：该隆起在**第一次可见的时间点**上的中心位置；`first_visible` 为 `unclear` 时，填你看到它的最早时间点的位置。
- 某个茎尖一个隆起都没有时，写一行：`Mxx,0,,,none,,`。

另附一段简短说明 `method.md`：你是看图判断还是写了判据；若写了判据，给出判据和代码。
