# A1：次级抑制场的配对消融（先于运行写定）

写定：2026-11-28。对应《模型改进实施方案》第三版第 4 步。用户 2026-11-28 指示“继续进展”；判据的规则按用户 2026-11-25 的要求写，等效范围和最低事件数是方案中的建议值，此前未单独确认，记录在此。

## 问题

在 v3 的抽样范围内，去掉 Besnard 形式的次级抑制场，叶序统计是否变化？

## 设计

- 代码：冻结的 `detuned_v3/frozen_v3/`（哈希已核对与 `detuned_v3/MANIFEST.sha256` 一致），不改。
- 参数：`detuned_v3/out/samples.json` 的 120 组、`calib.json` 的外围产生率（次级场不影响标定：标定时不起始原基）。
- 每组参数 × 种子 1、2 × 两个条件：**场开**（原样）与**场关**（k_rel = 0，其余不变）。共 480 次，运行到 1700。
- 保存每次运行的全部起始记录（时刻、位置），供以后按任何口径重算。
- 统计量按 `../observables.py` 与 `../OBSERVABLES.md`，分析时段 1250–1700。

## 判据

**统计单位是参数组。** 每组对每个种子算“场关 − 场开”的差值（两种条件下该指标都为正常时才算），再对可用种子取平均；参数组自助重抽样 2000 次，求均值的 95% 区间。

| 判定 | 条件 |
|---|---|
| 影响可忽略 | 95% 区间完全落入等效范围 |
| 有实质影响 | 95% 区间完全落在等效范围之外 |
| 证据不足 | 95% 区间跨越等效范围的边界 |

| 指标 | 等效范围 |
|---|---|
| 同时起始比例（按原基，12 h 窗） | ±0.05 |
| 原基间隔变异系数 | ±0.05 |
| P1–P5 方位离散 | ±2° |
| 平均发散角 | ±2° |
| 叶序类型改变的参数组比例（任一种子类型不同即算改变） | 0–5%：区间上限 ≤ 5% 为可忽略；下限 > 5% 为有实质影响；其余证据不足 |

只有全部指标都判为“影响可忽略”，结论才写“在 v3 抽样范围内，该场的作用可忽略”。

**事件数：** 每次运行保留实际事件数。“起始停摆”与“事件不足”分开（定义见 `OBSERVABLES.md`）。某指标上任一方停摆或事件不足，这一对不进入该指标的区间；另给“场开 × 场关”在正常、事件不足、停摆三类上的 3 × 3 交叉表。

**分组报告：** 全部 120 组；以及按 v3 的 R0（无运输时环内水平低于阈值，即起始受运输限制）分成两组。

## 预期与解读上的注意（写在运行之前）

- v3 中次级场参数与所有叶序统计的秩相关都小于 0.22，预期均值差小。
- 但 v3 的大多数运行不规则。在不规则的运行里，任何微小改动都会让轨迹分叉，两次运行的统计量差别接近两次独立运行的差别，区间会因此变宽，P1–P5 离散和平均发散角可能判为“证据不足”；叶序类型标签也可能因轨迹分叉而翻转。
- 为帮助解读（不参与判定），同时报告：同一参数组、场开条件下，两个种子之间类型不同的比例，以及各指标在两个种子之间的差值分布，作为“与扰动无关的随机差别”的参照。

**确认（2026-11-28，结果出来之前）：** 用户回复按建议值执行（原话“按和厂里的来”，理解为“按合理的来”）。等效范围与最低事件数照上表。
