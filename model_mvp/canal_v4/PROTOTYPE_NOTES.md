# 候选①（流量自我强化的排出通道）：机制原型记录

日期：2026-10-19。目的只是检查机制能否运作（会不会燃起、范围多大、是否只在环内起始、数值是否稳定），**没有计算任何叶序统计，也没有据此选参数**。
代码：`canal.py`（`CanalSim`，建立在冻结主线 v2 + 标定后几何之上），`proto.py`。依据核对：Bayer et al. 2009（Genes Dev 23:373，双重极化），
Deb et al. 2015（Development 142:1992，番茄，消融中脉使原基生长素暂时积累、叶序两个间隔后恢复），Mitchison 1980（Proc R Soc B 207:79，运河化）。

## 设计

每个细胞有排出能力 c；表皮向内层的转运 c·A/(1+A/K_e)，内层维管排出与对 PIN 的吸引都正比于 c；c 由通道自身承载的流量增强
（Hill 2），只在发生环内可以新起；去掉主线的四条规则（阈值放置、排除半径、跟随后定位、次级场），起始事件只记录、不施加。

## 三次原型

1. **反馈用总流入量（含被动交换）：** 全环几乎同时燃起（任一时刻 150–350 个排出细胞，环上生长素降到 1–2），排出区连成一圈。
   原因是被动交换在环上近乎均匀。这不符合运河化的本意（通道被自身流量增强），公式改正。
2. **只用通道自身流量、加小火种 c0，流量尺度按“J_K 的倍数”设定：** 没有任何燃起（环上 4.0 不变）。当初估算的燃起条件有误：
   低位状态消失的条件是 g(A) > J_K / (2√(c0 η))。改为由燃起水平导出 J_K（燃起水平 = 0.82 × 无原基环内水平，与主线阈值同一规则）。
3. **由燃起水平导出 J_K，由小长大起始，运行到 900（ρ_in 0/2，c0 = 1% / 3% η）：** 由小长大阶段燃起 70–150 次；
   环长到终值后（约 t > 450–550），环上生长素 3.8–4.1、高于燃起水平 3.28，却**再也没有通道燃起**，茎尖停止产生原基。

## 结论

一个开始排出的细胞先抽空自身的生长素；只有周围细胞的 PIN 同时汇聚到它、把生长素送进来，它才能维持并放大。主线工作在亚临界区间，
均匀的环上不会自发形成 PIN 汇聚点，所以通道起不来。这与 Bayer 2009 描述的次序一致：表皮先由“上梯度”极化形成汇聚点，
内部组织再“顺流”形成中脉。**排出通道位于汇聚点的下游，不能决定下一个原基何时何处起始，因此不能替代次级场与“跟随后定位”。**
缺失的机制更可能在表皮层自身（汇聚点如何依次形成）。是否继续及往哪个方向，待用户决定。

## 第二轮：回到表皮层（2026-10-19，用户选择）

目的：让 PIN 汇聚点自发形成、去掉阈值放置，排出通道作为下游（`proto_e.py`，`l1_map.py`）。仍只检查机制，不算叶序统计。

1. **表皮增益 b 回到文献值 3.0（Smith 2006 补充表 1），也试 2.5；其余为主线 v2 + 标定几何 + 内层 + 排出通道；四条规则全部关掉：**
   由小长大阶段有起始；环长到终值后（t > 550）茎尖停摆，400 个时间单位里只有 0–3 次起始（按原基间隔约 8，应有约 50 次）。
   环上生长素平均 4.1–4.4，高于燃起水平，但只有 1–2 个很浅的局部峰；各细胞的排出能力都只略升，停在“处处排一点”的均匀状态。
2. **无原基时的表皮自组织图（b = 2、3、4、6 × κ_c = 0、0.5、1.0、1.5 × ρ_in = 0、2，终值几何，运行 150）：**
   32 种组合里环上**没有一个**高出环平均 10% 的局部峰；扣除径向趋势后的圆周起伏 2–8%，个别 19–25% 也未形成峰。
   （外围产生率按 κ_c = 1.0 标定，其余 κ_c 下环内水平在 0.5–5.0 之间变化。）

## 第二轮结论

在“运输供给”结构下，生长素由外围经发生环流向中心，表皮的上梯度反馈被径向梯度主导，圆周方向的对称性不会自发打破，
与增益大小无关。v1（环上本地合成）在 b = 3 时可以自发成峰；结构改动一把合成移到外围、修好了“关掉运输仍长原基”，
同时也去掉了表皮自发形成汇聚点的可能。因此在现有模型族里，“无运输则无器官”（pin1/NPA）与“汇聚点自发形成”这两点互相矛盾；
新原基的位置只能来自已有原基造成的消耗场，“何时成为原基”只能由规则（阈值）给出。
