## 校准

内层会额外消耗表皮的生长素，因此要让无原基时环内水平仍为 4.0，外围产生率要比单层高：k_v = 0.3 时约 2.3–2.9 倍，k_v = 1.0 时约 4.3–5.6 倍
（例如终值发生环、ρ_in = 0：单层 4.03，k_v = 0.3 为 10.98，k_v = 1.0 为 21.36）。8 个校准点全部满足“无运输时环内水平低于阈值”（比值 0.13–0.49，阈值 0.82）。

## 事后诊断（种子 1、2 重跑；叶序标签与主运行逐一相同）

1. **读出是否只在原基处开启。** 在远离原基（> 2w）的细胞里：发生环和环与源区之间，所有组读出开启比例都是 0；
   **源区里，k_v = 1.0、ρ_in = 0 的四组有 14–39% 的细胞读出开启**（那里外围产生率高到 21 左右），k_v = 0.3 的组为 0–2%。
   所以 PL2 的通过在 k_v = 1.0、ρ_in = 0 时不是原基特异的。PL2 通过且源区开启比例 ≤ 2% 的组有 4 个：
   (ρ_in, k_v, K_e, η2) = (0, 0.3, 3, 1)、(0, 0.3, 3, 3)、(2, 0.3, 3, 3)、(2, 1.0, 3, 3)，全部是可饱和转运。
2. **原基是否仍是生长素最大区。** 原基中心生长素与环内远离原基细胞的平均值之比（中位数）：

   | | 0–1 个间隔 | 1–2 | 2–3 | 3–4 |
   |---|---|---|---|---|
   | 单层 | 1.4–1.7 | 1.25–1.4 | 1.15–1.35 | 0.7 |
   | 加内层，K_e = ∞ | 1.5–1.7 | 1.6–2.0 | 1.5–2.1 | 1.1–1.7 |
   | 加内层，K_e = 3 | 2.0–2.3 | 2.2–2.8 | 2.2–2.9 | 1.6–2.3 |

   中心是不是半径 w 内的最高点（采样时刻中是的比例）：年龄 0–1 个间隔，单层 33–48%、加内层 41–75%；1–2 个间隔，单层 28–44%、加内层 58–79%；
   3–4 个间隔，加内层降到 10–43%（单层此时中心已低于环的平均水平，比值 0.7）。
   加内层后原基保持为相对高点的时间明显变长，但“始终是局部最大”并不成立。
3. **发生环本身的水平。** 叶序形成过程中，环内远离原基处的平均水平只有 1.8–2.5，约为无原基时 4.0 的一半；
   加内层后比单层高一些（2.1–2.5 对 1.8–1.9）。
4. **抑制深度**（同 `../v2_supply/switch/` 的静态计算）：加内层后变浅，0.37–0.56，单层为 0.61（ρ_in = 0）和 0.54（ρ_in = 2）。
   `../v2_supply/switch/RESULTS.md` 里事后提出的“深度 ≥ 0.59 对生，≤ 0.57 螺旋”与这里的结局一致（加内层全部 ≤ 0.57、全部螺旋），
   但这次是先看到结局再算的深度，不能算作对该假设的检验。

## 其它变化

- 平均夹角 141.0–141.8°，比单层（约 140.5°）离 137.5° 更远。
- 原基间隔变短：7.5–8.7，单层为 9.6–10.9（同样的时间单位）。
- 加内层后，ρ_in = 0 时的交互对生消失（单层 6/8 → 加内层 0/64）。也就是说，`../v2_supply/switch/` 里看到的“本地产生作为开关”在加内层后不再出现。

## 结论

1. 加一层内层、让原基的汇把生长素送进内层而不是直接移除，可以让原基在起始后保持为相对的生长素高点，
   并让慢读出在原基处开启、滞后约 1–1.5 个原基间隔，接近 Galvan-Ampudia et al. 2020 的观察（DR5 晚于生长素约一个间隔）。
   这修补了留出检验 H8 的失败。
2. 这一效果主要来自“表皮向内层的转运可饱和”（K_e = 3）。线性转运时，只有内外交换较强（k_v = 1.0）才有类似效果，
   其中 ρ_in = 0 的两组在源区出现非特异的读出。
3. 代价：外围产生率要高 2.3–5.6 倍；平均夹角偏差变大约 1°；对生不再出现，叶序类型对本地产生不再敏感。
4. 原基中心并非始终是局部最大：年龄 3–4 个间隔时多数时刻已不是。
