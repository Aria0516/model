# 主线 v2 的尺度标定（先于查看 21 个茎尖的数据写定）

写定时间：2026-10-14。被标定的版本：`../frozen_v2/`（运输供给 + 内层）。
数据：Galvan-Ampudia et al. 2020 的 21 个 qDII–CLV3–DR5 茎尖（Zenodo 3737795，每个 0、5、10 h 三个时间点），
用作者的 `sam_spaghetti` 管线（`../../reproductions/elife55832/`，已在 E27/SAM7 上原样复跑）处理。

**已看过的数据：** E27/SAM7（八月的复现）。本方案的测量方法在 SAM7 上设计；其余 20 个茎尖在本方案写定前未处理、未查看。
SAM7 上的粗看结果：L1 细胞核最近邻间距约 4.4–4.7 µm，CLV3 半径 28.2 µm。

## 目的

模型的长度单位是“细胞直径”，目前所有几何量都是按假定的细胞大小拟定的。本轮只做一件事：
**把几何量换成实测输入，其它一律不动，看叶序和夹角是什么。** 时间、浓度、动力学参数没有实测值，本轮不标定。

## 输入（由数据定，定完不再改）

每个茎尖分别测，取 21 个的中位数；同时报告四分位范围。

| 模型量 | 数据量 | 测法 |
|---|---|---|
| 细胞直径 d（换算单位） | L1 细胞核最近邻间距 | 对齐后 L1 核的三维坐标，半径 60 µm 以内，每核取最近邻距离的中位数；三个时间点合并 |
| 发生环内半径 R_c | CLV3 区半径 | 管线给出的 `clv3_radius`，除以 d |
| 原基范围 w | P0 生长素最大区的宽度 | 在 P0 极值点 15 µm 以内的 L1 核上，对生长素（1 − qDII，管线的 `Auxin`）拟合各向同性二维 Gaussian 加常数，取标准差 σ；w = σ / d |

**不标定、保持主线取值的量：** 发生环宽度 2 个细胞；源区在发生环外 2 个细胞；κ_c = 1.0；内层三个量；ρ_in 0 与 2；
增益、阈值比例、次级场、跟随后定位。外围产生率 ρ_far 按原规则（无原基时环内水平 4.0）在新几何上重新确定，只用无原基状态。
由小长大的起始仍从内半径 2.0 开始，在 600 内长到新的 R_c。R_out = R_c + 9。

## 修订一（在开发茎尖 SAM7 上试测后、处理其余 20 个茎尖之前，2026-10-14）

1. **w 不再由数据确定，保持主线值 2。** 原定的测法（P0 周围 15 µm 内拟合二维 Gaussian）在 SAM7 上三个时间点全部失败
   （σ 落到拟合边界 40 µm 或 1 µm）。原因：1 − qDII 在中央区到 P0 一带都接近饱和（约 0.95），P0 在径向上不是孤立的峰。
   沿方位方向有清楚的峰，但在周期性的排列里，这个峰的宽度主要由相邻原基的间距决定，而间距正是评价量（G、发散角）所反映的；
   拿它当输入，会把评价量的信息带进输入。因此本轮只标定 d 与 CLV3 半径。
2. **P0 方位峰宽改为评价量。** 测法（数据和模型相同）：在 P0 半径 ±5 µm 的环带上，以 15° 为一格求生长素随方位的平均；
   峰值取 P0 所在格，两侧各取 ±90° 内的最低值，求两侧到达“峰与该侧最低值的中点”的方位，二者之差乘以 P0 半径即为宽度（µm）。
   模型侧用原基位置固定时刻的表皮生长素场。数据侧只用 0 h（与 P0 半径相同）：同一序列里 P0 的编号跟随同一个器官，
   5 h、10 h 时它已长大外移（SAM7：0、5、10 h 分别为 37.6、63.7、70.5 µm）。
3. **换算单位按同一口径：** 模型侧也用细胞中心的最近邻距离中位数作为“一个细胞”的长度（模型网格并非严格以 1 为间距），
   即 µm/模型单位 = d_数据 / d_模型。
4. 上面“输入”表中 w 一行作废；其余不变。

## 修订二：图像裁剪（处理 21 个茎尖之前，2026-10-14）

作者的管线在 `TIF-No-organs/` 下有同名裁剪图时自动改用裁剪图（`sam_microscopy_loading.py` 第 65–75 行）。
裁剪图是手工画的二维区域，对所有 z 层相同（SAM7：保留中心周围半径约 45–80 µm，有老器官的方向裁得更靠里）。
Zenodo 只有原始 CZI；作者网站上的裁剪图只有 E27/SAM7 一个（不在这 21 个之内），其余链接返回 404。
不裁剪时，SAM7 的第一张图检测到 3203 个峰（裁剪后 1500 个），表面网格大近 3 倍，运行在生成网格时被杀掉。

做法：以 CLV3 最大投影（5 µm Gaussian 平滑、取半高以上加权）的中心为圆心，保留半径 60 µm 的圆柱，其余置 0，
写成与作者裁剪图相同格式的文件，放在管线会去找的位置（`docker/make_crop.py`）。半径 60 µm 事先定为覆盖作者裁剪区域
90% 半径（64 µm）的整数值，不随结果调整。已核对：按作者文件的排列 (x,y,z)→(z,c,y,x)，作者裁剪图在保留区内与 CZI 一致；
我们写出的文件经管线读回与写入逐体素相同。

**在 SAM7 上的通过标准（写在比较之前）：** 同一管线分别用作者裁剪和自动裁剪处理 SAM7，
d 相差 ≤ 3%，CLV3 半径相差 ≤ 2 µm，0 h 的 P0 半径相差 ≤ 3 µm，0 h 的 P0 方位峰宽相差 ≤ 25%，手性判定相同。
另核对作者裁剪这一路是否重现八月 notebook 的结果（核数 1627/1517/1500）。不通过则不用自动裁剪处理 21 个茎尖，先报告。

**对照结果（2026-10-14，`validate_crop.py`）：通过。** 作者裁剪这一路三个时间点的对齐数据与八月 notebook 逐字节相同。
作者裁剪 / 自动裁剪：d 4.56 / 4.58 µm，CLV3 半径 28.22 / 27.82 µm，0 h P0 半径 28.54 / 28.07 µm，0 h P0 峰宽 37.6 / 38.8 µm；
手性自动判定为 −1，与作者相同，但余量小（总分 ±1.46，作者裁剪下 +6.55，三个时间点符号不一）。
本轮的四个量都不依赖手性（P0 方向在翻转前确定，翻转只改变其余原基的编号），因此手性只记录、并标出余量小于 2 的茎尖。

## 质量控制（数据侧）

- P0 的确定：管线自动标注的 `primordium == 0` 且 `extremum_type == minimum`（qDII 极小 = 生长素极大），半径在 15–50 µm 之间；
  不满足的时间点不用于 σ，照实记录排除数。自动标注未经作者的人工校正，这是已知的不确定来源。
- 拟合失败（σ 不在 2–20 µm 或拟合不收敛）的照实记录排除数。
- 若某个茎尖的 SAM 朝向（手性）无法自动确定，该茎尖不进入 σ 的统计，其余两项照用。

## 预期（写在看数据之前）

- 若 d 与 SAM7 相近（约 4.5 µm）、CLV3 半径约 28 µm，则 R_c 约 6.2，比主线的 5.5 大；起始半径会落在约 30–33 µm，
  “40 µm 对 30 µm”的不符主要来自当初假定的细胞大小。
- w 事先不知道。若 σ 换算后明显小于 2（例如 1.5 以下），按 `n10` 的经验，叶序的规则性会下降，并且会变得依赖预留半径；
  若 w 约为 2，(R_c + 1)/w 由 3.25 升到约 3.6，预期仍是螺旋，置换可能增多。
- 平均夹角预期不会因此接近 137.5°（之前改几何时它基本不动）。
- 无论结果如何，都按上表报告，不因结果回头改输入的测法。
