# 生长素–PIN1 叶序模型 v1

研究问题：生长素如何决定茎尖原基的位置，从而形成螺旋、对生或轮生叶序。
运行环境：`C:\Users\xczhang\software\Conda\python.exe`（需要 numpy、scipy、matplotlib、imageio），在本目录下运行各脚本。

## 1. 方程

茎尖表皮俯视为一层细胞。细胞是物质点的 Voronoi 区域；组织以速率 γ 均匀膨胀，细胞面积超过 `v_div` 时分裂，
越过 `R_out` 后移出。子细胞继承母细胞浓度。长度单位为细胞直径，时间单位任意（原基间隔由模型给出）。

生长素浓度 A_i：

    dA_i/dt = (ρ_i + S_i)/(1 + κ_A A_i) − (μ + 2γ) A_i − η_i A_i − (1/V_i) Σ_j J_ij

    J_ij = D (l_ij/d_ij)(A_i − A_j) + T [ P_ij u(A_i)/(1 + κ_T u(A_j)) − P_ji u(A_j)/(1 + κ_T u(A_i)) ],  u(A) = A²

每个细胞的 PIN1 总量有限，按邻胞信号在各面之间分配：

    P_ij = p0 V_i φ_i · l_ij ψ_ij b^{C_j} / Σ_k l_ik ψ_ik b^{C_k},   C_j = A_j + A_q s_j

区域：发生环 R_c ≤ r < R_p 内 ρ_i = ρ_pz，环外 ρ_i = ρ_out。

原基 m 在 t_m 产生于 x_m，之后随组织外移。身份场 s_m(x) = exp(−|x − x_m|²/2w²)：
汇 η_i = η Σ_m a_sink(龄) s_m；极化线索 s_i = max_m a_cue(龄) s_m；源 S_i = ρ_src Σ_m a_src(龄) s_m。

记忆与读出：τ_M dM_i/dt = A_i − M_i；τ_R dR_i/dt = G_i H(M_i − θ) − R_i。

起始规则：环内细胞 M_i ≥ Th，且距所有已有原基超过 r_ex，即产生新原基，中心取峰附近的加权质心。
**没有任何角度、原基间隔或手性被写入模型。**

## 6. 主要结果（各项均为多个网格种子的统计）

**(1) 运输反馈的工作区间决定是否规则。** Smith 型增益（b = 3）下，均匀态在生长素约 2.7 以上即失稳，
增长时间约 0.16，而原基间隔约 7–20；原基位置由细胞尺度噪声成核决定，夹角离散、次序频繁置换。
“符合主导夹角的比例”在该工作点为 0.58。两步改动把它提高到 0.95–0.98（8/8 个种子为规则螺旋）：
先把环外产生率降到 2 并把汇范围加到 3，使环外不再成核（0.85，5/8）；再把增益降到 b = 2.0，使环内也不自发成核，
原基位置由平滑的耗竭场越过阈值决定，并加入适度的时间积分。

**(2) 只改发生环大小，叶序类型依次变化**（`out/fig_types.png`、`out/fig_phase.png`）。
环中线半径与汇范围之比约 0.9–1.15：二列互生（约 175°）；1.2–1.4：过渡角（约 155°）；1.4–2.0：螺旋（134°–142°）；
2.0–2.75：交互对生（每节 2 个，相邻节转约 87°）；大于 2.8：径向比接近拟南芥（G 约 0.2）的螺旋，但次序置换多。
对数径向比 G 是自发出现的量。

**(3) 时间积分的作用取决于工作区间**（`out/fig_tau.png`）。亚临界时，回路内的泄漏积分取 τ_M 约为原基间隔的
0.05–0.3 倍，使规则螺旋由 4–6/8 提高到 7–8/8；τ_M 达到间隔的 0.5 倍以上则破坏叶序并偏向二列互生。
超临界时任何 τ_M > 0 都使叶序变差。

**(4) 虚拟扰动（`e15`，螺旋工作点，8 个种子）。**
去掉极性运输（T = 0）：规则螺旋 0/8，但原基仍然产生——与 pin1/NPA 无器官的表型不符；
去掉原基汇：原基过密、无序；去掉原基极化线索：1/8；
去掉“生长素→PIN”反馈但保留指向原基的极化：变为规则的二列互生（7/8）。
即本工作点下必需的是极性运输、原基汇和指向原基的极化；上梯度反馈改变叶序类型，但不是规则性的必要条件。

**(5) 模块 M2、M3、M4（`e13`、`e16`、`out/fig_modules.png`）。**
基线中央区生长素（1.8）低于发生环（2.5），PIN 无整体向心性（指数约 0）。
M2 向心偏置 0.5 使 PIN 向心指数升到约 0.3、中央区升到 2.35，同时把螺旋变成交互对生（5/6）；偏置 1.0 时中央区高于环，但叶序不规则。
M3 老原基转源使规则性下降（0–1/6）；浓度型极化不会自发把外围源的生长素导向中心（向心指数不变）。
M3 与向心偏置合用时 6/6 个种子规则，但类型不一：4 个夹角约 125°，1 个螺旋，1 个交互对生；平均 G 约 0.27、单步角噪声 8.4°。
M4：原基起始后其生长素被汇迅速排空（峰值出现在起始后 0.2），慢读出（τ_R = 15）从不开启；改用 Smith 型封顶汇可让原基保持为最大区，
但叶序不规则（0/6）。也就是“规则叶序”与“原基在起始后维持高生长素约两个间隔”在单层模型里目前不能兼得。

**(7) 降噪专项（`n01`–`n05`，`out/fig_noise.png`）。**
在拟南芥的径向比附近（G≈0.24），问题主要不在角度精度，而在原基间隔不稳造成的次序置换：
无置换的运行里角度离散约 9°，但 16 个种子只有 5 个规则，间隔变异系数 0.56，29% 的夹角不符合主导角。
加入一个作用于起始判据（不作用于生长素）的次级抑制场后，规则的种子升到 11–12/16，间隔变异系数降到 0.21–0.30，
不符合主导角的比例降到 10%–20%。Besnard 2014 在茎上测得的非规范夹角比例为野生型 15%、ahp6 突变体 37%，
模型“加场 / 不加场”与“野生型 / 突变体”的方向和量级一致。
起作用的是“即时出现、范围覆盖全环、寿命约 0.25–0.5 个间隔”的场；设成“延迟约一个间隔出现、范围 4–9 个细胞”时，
12 组参数中 10 组的间隔变异系数仍为 0.53–0.70，另外 2 组降到 0.32 但径向比同时升到 0.34–0.38，都不算解决。
全环场把交互对生点转成螺旋（5/8），局部场则保留交互对生（5/8）：同一几何下次级场的范围决定得到螺旋还是对生。
角度精度方面，18 种单项改动（读出方式、扩散、汇强度、线索、记忆时间、阈值、生长率、环宽、细胞大小、增益、周转）
都不能明显降低相邻原基的离散（9°–13°），相当于约 0.75 个细胞直径的落点误差。

**(8) 三项候选处理（`n06`–`n09`，`out/fig_error_reduction.png`）。**

① 跟随后定位（有效）。位点在第一次过阈值时只被预留并发出次级场，随后在 τ_c 内跟随局部生长素最大区，
再固定位置、打开汇和极化线索。拟南芥径向比处 16 个种子：规则的由 12/16 升到 16/16（15 个螺旋、1 个 Lucas 螺旋），
非规范夹角由 17% 降到 1%，间隔变异系数由 0.21 降到 0.15，P1–P5 相对夹角的离散由 9.0° 降到 5.4°（实测 6.7°）。
时间步减半、排除半径取 2 或 4.5 结果不变；跟踪半径取 2.0、2.5、3.0 时离散为 7.1°、5.2°、4.2°。
径向比 0.21 处由 5/10 升到 10/10；螺旋点加次级场后为 9/10，离散由 14.3° 降到 8.0°。
它必须与次级场同用：没有次级场时，延迟打开汇会让多处同时起始（规则的 0–4/10）。
另一种写法“等 3–7 个细胞成片过阈值再取质心”效果不明显（离散 7.5°–10.3°）。
主导夹角仍为 139.9°–140.2°，没有改变。

③ 汇随年龄变化（无效）。汇范围随年龄增大使叶序偏向二列互生或失序（规则的 0–3/10）；
汇与极化线索随年龄消退为 2–3/10；只让汇消退为 7/10，与参照的 9/10 相近但不更好。主导夹角没有被稳定地拉近 137.5°。

⑤ 中央区作为共享的生长素库（无效）。8 种变体全部破坏叶序（规则的 0/10），间隔变异系数升到 0.7–1.8，
出现每节 3–5 个原基的无序成簇起始。共享供给让各处同步上升，起到的是“同步”而不是“不应期”的作用。

**(9) 两处具体不符的检查（`n10`）。**
起始半径：把发生环和汇范围按比例缩小到环 4–6、汇范围 1.5，起始半径由 42 µm 变为 31 µm，主导夹角 137.8°，
但规则的由 10/10 降到 8/10，P1–P5 离散由 5.0° 升到 7.4°，径向比升到 0.31，并且变得依赖位点的预留半径（取 2 时只剩 1/10）；
再小（环 3.5–5.5、汇范围 1.4）为 1/10。即半径可以对上，代价是稳健性，因为汇范围已接近单个细胞。
无极性运输仍有原基：无原基时环内生长素水平在 T = 0 时为 3.93，T = 22.5 时为 4.02，运输只贡献约 2%，阈值 3.3 低于两者；
改变产生率在环内外的分配（5 种）差距仍不超过 3%。把阈值提到无原基水平之上并提高增益（9 组），无运输时确实不再产生原基，
但有运输时规则的只有 0–3/8。即这一条不能靠调参数解决，需要让环内生长素的供给本身依赖极性运输。

**(10) 留出检验（`frozen_v1/`、`heldout/`）。**
把当时的模型冻结为 `frozen_v1/`（含哈希清单），先在 `heldout/PROTOCOL.md` 写下文献结果和判定标准，再运行，结果见 `heldout/RESULTS.md`。
10 项中通过 3 项（手性无偏、对生起始过渡到螺旋、径向定位精度），部分通过 1 项（去掉一个原基的汇），无法判定 1 项，
不通过 5 项。最重要的两条：关掉极性运输后仍产生原基，且 3/8 仍是规则螺旋——冻结版本的排列机制实际上不依赖极性运输；
去掉次级场后叶序崩溃，远比实际的 ahp6 表型严重。

**(11) 结构改动一：环内生长素由极性运输供给（`v2_supply/`）。**
把生长素的产生移到发生环之外的外围，加整体向心的 PIN 偏置，中央区 PIN 量降低；方案先于运行写在 `v2_supply/PROTOCOL.md`。
在预先定好的 24 组取值中，20 组满足设计要求。这 20 组里，关掉极性运输后全部不再产生原基，中央区生长素为发生环的 0.98–1.76 倍。
代价是类型选择变得不确定：在冻结工作点的发生环上，72 次运行中规则的 43 次，其中普通螺旋 20、Lucas 螺旋 18、交互对生 5；
没有次级场和跟随后定位时全部不规则；从对生起始时，交互对生可以维持（36 次里 13 次），不再全部过渡到螺旋。详见 `v2_supply/RESULTS.md`。
这一结构尚未并入默认参数，`frozen_v1/` 保持不变。

**(12) 新结构下类型为什么不确定（`v2_supply/why_types/`）。**
各类型能各自维持，不来回切换（从噪声起始的 53 次规则运行里换类型的为 0）；落到哪一种取决于起始方式。
并存的程度取决于分生组织内有没有本地产生：本地产生为 0 时普通螺旋、Lucas 螺旋、交互对生都能维持；为 2 时普通螺旋是主要归宿。
发生环由小长大时不再出现 Lucas 螺旋，但普通螺旋的比例没有上升（38% 变为 27%）：本地产生为 0 时走向交互对生（23/32），
为 2 时走向普通螺旋（17/32），不规则的运行增多。详见 `v2_supply/why_types/RESULTS.md`。

**(13) 由小长大为什么走向对生、为什么不规则增多（`v2_supply/ramp_mech/`）。**
成对的两个原基相隔时间的中位数为 4.0，正好等于次级场寿命：第一处起始后，对侧只被压住约 4 个时间单位，之后对侧补发。
沿时间看，每次运行第一个规则的阶段多数已是交互对生，不是先经过二列互生。
上一项看到的不规则多是尚未收敛的过渡：保持阶段延长到 1700 后，不规则由 23/64 降到 8/64。
次级场寿命改为 8 或 16 时对生消失，但得到的是不规则而不是螺旋：结果依赖这个唯象参数的取值。详见 `v2_supply/ramp_mech/RESULTS.md`。

**(14) 本地产生是不是对生与螺旋之间的开关（`v2_supply/switch/`）：部分确认。**
κ_c = 1.0 时是：ρ_in 从 0 到 1，1250–1700 时段的交互对生由 14/16 降到 1/16，螺旋由 0 升到 11/16，转折在 0.5 附近。
κ_c = 1.5 时不是：即使没有本地产生，螺旋也有 13/16。直接从终值起始时开关弱得多（ρ_in = 0：对生 2/8，Lucas 4/8）。
事后观察（未检验）：两档 κ_c 合在一起看，结局似乎由“一个原基对相邻发生环的抑制深度”决定，深度 ≥ 0.59 对生，≤ 0.57 螺旋。
详见 `v2_supply/switch/RESULTS.md`。

**(15) 结构改动二：内层汇（`v3_layer/`）。**
原基的汇不再直接移除生长素，而是送进下方的内层；内层有横向扩散、周转、与表皮的交换和原基下方的维管排出。实现为子类，`model.py` 未改。
预先判定全部通过：原基起始后保持在阈值以上的时间变长（16 组中 11 组 ≥ 1 个原基间隔，单层 0.07），
慢读出在原基处开启、滞后约 1–1.5 个间隔，关掉极性运输仍不产生原基。这修补了留出检验 H8 的失败。
事后诊断：效果主要来自表皮向内层的转运可饱和；内外交换强（k_v = 1.0）、无本地产生时读出在源区也会开启（14–39%），不特异；
原基中心并非始终是局部最大。代价：外围产生率高 2.3–5.6 倍，平均夹角 141.0–141.8°，交互对生不再出现（128 次全为螺旋）。
详见 `v3_layer/RESULTS.md`。

**(16) 主线 v2（`frozen_v2/`，2026-10-14 冻结）。**
冻结版 v1 + 结构改动一 + 结构改动二，内层取 (k_v, K_e, η2) = (0.3, 3, 3)：这是 8 组里唯一一组在 ρ_in = 0 与 2 上都满足 PL1、PL2 且读出特异的，
选择规则在看过结果之后定，不涉及叶序统计。ρ_in 0、2 两档都保留。参数全部写在 `frozen_v2/mainline.py`，重现开发目录的运行逐位相同。
之后的标定和检验都在这一版本上做。

**(17) 尺度标定（`calib_v2/`）。**
用 Galvan-Ampudia 2020 的 21 个茎尖（Zenodo 3737795）和作者的管线（`../reproductions/elife55832/`）测细胞间距与 CLV3 区半径，
作为几何输入；其余不动。方案见 `calib_v2/PROTOCOL.md`（含两次在处理 21 个茎尖之前的修订：原基宽度不作输入、图像自动裁剪）。
开发用茎尖 E27/SAM7（不在这 21 个之内）上：L1 细胞间距 4.56 µm，模型细胞间距 0.922 个单位，即一个模型单位约 4.95 µm。
21 个茎尖：L1 细胞间距 4.53 µm（四分位 4.48–4.57），CLV3 半径 27.3 µm（27.0–27.9）。换算后 1 个模型单位 = 4.91 µm，
发生环内半径 5.57（主线 5.50），几乎没有改动。用实测细胞大小换算，主线的起始半径 26–29 µm，与实测 P0 半径中位数 29.0 µm（26.0–33.3）相合；
P0 方位峰宽模型 35–40 µm，实测 44 µm（38–52）。仍不相符：模型过于规则（P1–P5 离散 3° 对 6.7°，非规范夹角 0% 对 15%，
间隔变异系数 0.14 对 0.22），平均夹角 141.3–141.5°。详见 `calib_v2/RESULTS.md`。

**(18) 结构改动三：细胞间 PIN 量的随机差异（`noise_v3/`）——不足以解释实测的不规则，不并入主线。**
每个细胞的 PIN 总量乘以对数正态因子（对数标准差 σ），分裂时子细胞重抽。原定用数据中相邻细胞 qDII 的局部残差（0.224）确定 σ，
但模型在 σ = 2 时也只到 0.12–0.14，且不响应生长素的 TagBFP 自身就有 0.155，该锚点作废。按用户选择改为两步：
剂量扫描显示 σ ≤ 0.25 时仍规则，0.3–0.5 之间转为次序置换与失序；ρ_in = 2、σ = 0.3–0.4 时 P1–P5 离散 6–9°、间隔 CV 0.20–0.24，
与茎尖实测相近，但没有非规范夹角；没有一个 σ 能同时对上非规范夹角 15% 和离散 6.7°。推断 σ_need = 0.32（ρ_in = 0）/ 0.48（ρ_in = 2），
再用 4 个 PIN1 茎尖（作者的壁分割管线，做了一处 Python 3 兼容修补）直接测细胞间 PIN1 差异：σ_PIN 中位数 0.080（0.064–0.107），
远低于所需，判定为“不足以解释”。把实测值（0.08、0.12）放进模型，P1–P5 离散只从 3.1–3.4° 增到 3.4–4.0°，仍远比实测规则。
模型过于规则的原因不在 PIN 量的细胞差异。平均夹角不受随机性影响，仍为约 141°。详见 `noise_v3/RESULTS.md`。

**(19) 寻找两个唯象部件背后的机制（`canal_v4/`、`mp_v5/`）。**
目标是用机制取代“即时、覆盖全环”的次级场和“跟随后定位”。(a) 由流量自我强化的排出通道（运河化）自己起不来：开始排出的细胞先抽空自身，
它只在汇聚点下游。(b) 在运输供给结构下，单靠生长素浓度的上梯度反馈，表皮在任何增益（b 2–6）和向心偏置下都不自发形成汇聚点。
(c) 让细胞的生长素响应（类 MP；Bhatia 2016）吸引 PIN 并向内排出后，不放置原基也能自发、持续地形成分立原基，且无运输时不形成；
但原基成簇同时起始（19–66%），叶序成为不规则的多轮或轮生，规则 0–1/16，判定不通过。位置可以自发产生，“一次一个”的时序仍需要另一种机制；
即时、覆盖全环的抑制在文献中尚无明确的分子对应。详见 `canal_v4/PROTOTYPE_NOTES.md`、`mp_v5/RESULTS.md`。
（更正：Besnard 2014 显示野生型约 28% 的起始是两个原基几乎同时出现，`mp_v5` 的“成簇起始 ≤ 5%”判据没有数据依据，见其 RESULTS 更正节。）

**(20) 主线 v3：去掉按叶序结果挑选的设定（`detuned_v3/`，冻结于 `detuned_v3/frozen_v3/`）。**
b 改为 Smith 的 3，去掉“跟随后定位”，次级场改为 Besnard 2014 的形式（延迟、局部），τ_M 按 Galvan-Ampudia 2020 的暴露时长（时间单位按实测生长率换算，1 单位 ≈ 1.6 h），
其余 15 个无锚点参数在事先写定的范围内拉丁超立方抽样 120 组（用户确认允许，只报告分布、不挑选）。结果：88% 的运行不规则，规则螺旋 11%
（全部来自“起始受运输限制”的样本，其中占 19%）；有序与否主要取决于未测量的原基抑制范围 w、向心偏置 κ_c 与汇强度 η；Besnard 形式的场几乎不起作用；
规则螺旋的运行平均夹角仍为 141°、离散 21°、间隔 CV 0.46，没有一次运行同时落在全部实测范围内。未经调整而与数据大体相符的：原基间隔（规则螺旋 13.8 h，实测 12 ± 2 h）
与同时起始比例（36%，Besnard 野生型约 28%）。v2 的有序主要来自当初的调参。详见 `detuned_v3/RESULTS.md`。

## 7. 局限

- 平均夹角偏大约 2.5°（140.0° 对 137.5°），上述处理都没有改变它。
- ~~发生环半径约 40 µm 对实测约 30 µm~~：已由 `calib_v2/` 解决——那是按约 6 µm 的细胞换算造成的；按 21 个茎尖的实测细胞间距（4.53 µm）换算，
  主线起始半径 26–29 µm，与实测相合。时间与浓度仍是任意单位。
- 主线 v2 比实测规则得多（P1–P5 离散 3° 对 6.7°，非规范夹角 0% 对 15%）：模型除细胞网格外没有随机性来源。
- 该工作点比实测更规则（非规范夹角 1% 对野生型 15%，间隔变异系数 0.15 对 0.22）：模型除细胞网格外没有随机性来源。
- 三个成员的轮生基本得不到：以三个互成 120° 的原基起始，144 次运行中只有 1 次维持为三轮生，其余退回带置换的螺旋或无序（`e14`）；加全环次级场后同样被转成螺旋。
- 不加次级场时，拟南芥的径向比处以螺旋为主（约 140°），但只有 5/16 个种子规则。
- 次级场目前只在“即时、宽范围、短寿命”的形式下有效，这与 Besnard 2014 描述的 AHP6（晚于 DR5 约一个间隔出现、局部分布）并不一致；它对应什么生物学信号是开放问题。
- 交互对生约有一半种子完全规则，其余为带缺陷的成对排列；对细胞大小敏感。
- “跟随后定位”和次级场都是唯象设定：前者对应“最大区先出现、再收窄定位”的观察（Galvan-Ampudia 2020），后者的生物学对应不明。
- 原基身份、汇范围 w、极化线索 A_q 和向心偏置 κ_c 都是唯象设定。
- 默认模型只有表皮一层；`v3_layer/` 加了一个与表皮同几何的内层，但没有维管束的空间结构，尚未并入默认参数。
- 参数未经实验标定，时间与浓度单位任意。
